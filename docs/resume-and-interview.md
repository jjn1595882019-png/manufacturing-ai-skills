## 简历项目模板

**制造业业务辅助 Agent Skills｜个人项目**

围绕制造业备料和生产交接场景，使用 SKILL.md 封装业务步骤与输出规范；通过 Python 脚本实现多层 BOM 理论用量展开及库存缺口计算，输出可追溯的物料来源、缺料和待核实信息；设计生产异常交接模板，区分事实、缺失信息与人工确认事项。

技术：Agent Skills、Prompt / SOP 设计、Python、JSON、Decimal、unittest、Git。

注意：只有在真实运行、理解并亲自参与相关工作之后，才能写对应职责；仓库中没有 RAG、模型微调、企业接入或已上线部署，不应写成具备这些交付成果。无虚构性能、企业用户或提效指标。

## 应能解释的问题

1. 为什么 BOM 使用递归？同一物料由两条路径引用时如何汇总？遇到循环怎么办？
2. 损耗率的口径是什么？为什么示例用 Decimal，而不是二进制浮点数？
3. 缺料如何计算？在途尚未到货时，为什么要给出不含在途的缺口？
4. 为什么库存缺失不能直接写成零？单位不一致、已分配大于现存怎么办？
5. Skill 和 Python 脚本分别负责什么？为什么不能让大模型心算 BOM？
6. 生产异常交接如何区分事实和推断？缺失负责人、原因和恢复时间怎么办？
7. 当前项目与真正 MRP 的差距是什么？如何增加时间维度、替代料、批次和安全库存？

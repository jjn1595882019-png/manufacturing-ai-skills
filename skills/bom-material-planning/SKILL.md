# BOM 用料核算

使用用户提供的 BOM 数据和目标生产数量。若输入缺少父子关系、每级单位用量、生产数量、物料单位或损耗口径，先指出缺失项；不要自行补造。

1. 确认数据结构、目标产品、数量以及各级损耗。脚本的损耗公式为 `本级需求 = 上级需求 × 单位用量 × (1 + loss_rate)`；如果企业采用其他公式，先说明不能直接套用。
2. 将已确认的数据整理为与 `examples/bom.json` 一致的 JSON。`materials` 中每个物料必须有唯一编码和单位；`bom` 的边包含 `parent`、`child`、`quantity`、`loss_rate`。没有损耗时显式写 `0`。数量、损耗建议用十进制字符串。结构中未出现为父项的物料视为叶子，须确认 BOM 已提供完整。
3. 运行本 Skill 的 `scripts/explode_bom.py INPUT.json`。如需文件供其他 Skill 使用，增加 `--output OUTPUT.json`。脚本按根产品展开，最终只汇总叶子；发现循环、缺失物料、无效数值或重复边时停止并说明错误。
4. 输出汇总需求、单位、计算口径和关键来源路径；如果 BOM 可能不完整，明确提醒结果只是基于给定 BOM 的理论需求。不得声称结果已扣库存或已形成采购单。

使用用户提供的真实资料时，不要自行上传、发布或写入外部系统。该计算不处理替代料、批次、最小包装或单位换算。
